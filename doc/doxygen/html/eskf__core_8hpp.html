Detailed Description

21-state ESKF C++ header.

Full port of Python eskf.py to standalone C++17 + Eigen3. Standalone dependency-free implementation. Runs on Raspberry Pi / ARM. Supports SCHED_FIFO real-time scheduling Designed for hard real-time execution.

State layout (same as Python version): Nominal (21): [pos(3), vel(3), quat(4), accel_bias(3), gyro_bias(3), baro_bias, clk_bias, clk_drift, wind_n, wind_e] Error (20): [dp(3), dv(3), dtheta(3), dba(3), dbg(3), d_baro, d_clk, d_clk_drift, d_wind(2)]

Features:

  • Covariance convergence detection (z_cov < 0.25 + step > 200)
  • Adaptive process noise (scales with vibration magnitude)
  • ZUPT (zero velocity update)
  • Baro drift compensation (bias estimation)
  • Mag auto-cal (magnetic distortion rejection)
  • GPS fusion (WGS-84 to NED local tangent plane)
  • Generic external measurements (modular update framework)
  • Lidar range + radar velocity (high-bandwidth relative updates)
  • Optical flow (GNSS-denied velocity tracking)

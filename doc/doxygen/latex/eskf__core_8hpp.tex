\doxysubsection{Detailed Description}
21-\/state ESKF C++ header. 

Full port of Python eskf.\+py to standalone C++17 + Eigen3. Standalone dependency-\/free implementation. Runs on Raspberry Pi /\+ ARM. Supports SCHED\+\_\+\+FIFO real-\/time scheduling Designed for hard real-\/time execution.
